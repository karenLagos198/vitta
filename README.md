# Vitta
**Vive más, olvida menos.** Organizador personal web: tareas, finanzas y recordatorios en un solo lugar.

## Estructura
```
vitta/
└── frontend/   (index.html, style.css, app.js, nn.js)
```
## Estado
Primera versión del Front-End (resumen, tareas, finanzas, recordatorios y Asistente IA).
Los datos son de ejemplo en memoria; backend (Flask) y base de datos (SQLite) vendrán en próximas entregas.

## IA
`nn.js` implementa una red neuronal pequeña (1 capa oculta, backpropagation) que predice la categoría de un gasto a partir de su texto.


## Ejecutar
1. Descargar o clonar este repositorio.
2. Entrar a la carpeta `frontend`.
3. Hacer doble clic en el archivo `index.html` (se abre con tu navegador).
